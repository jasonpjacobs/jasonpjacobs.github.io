# portfolio-site

GitHub page that shows off the sabbatical tools

Part of my sabbatical portfolio. The hub's `../CLAUDE.md` (loaded automatically) explains how
projects relate and how sessions coordinate; `../PROJECTS.md` lists the other projects.

## Phase

Requirements gathering. Help me sharpen the idea: ask probing questions, challenge assumptions,
suggest scope cuts, and record what we settle. Don't write application code yet.

## Docs (the source of truth; keep them current)

- `docs/vision.md` — problem, audience, why it matters, what success looks like.
- `docs/requirements.md` — numbered requirements (`R-001`…) with priority.
- `docs/open-questions.md` — unresolved questions; move answers into requirements or decisions.
- `docs/decisions/` — project-local decisions, numbered `NNNN-title.md`.

## Boundaries

- Read sibling projects (`../<project>/docs/`) and the hub for context whenever it helps.
- Write only inside this folder. For anything affecting another project, message that
  project's session or propose a hub decision in `../decisions/`.
